# 호두 · 네 착장의 전신 여백 수정

제작 도구: built-in image_gen. 원본 각 프레임에서 우측/하단 꼬리털이 잘리는 문제를 발견하여 전체 카메라를 조금 뒤로 옮기는 편집. 수동 그림 편집이나 임의 확대는 하지 않음.

최종 검토 승인: root가 네 수정 원본을 직접 확인하고 모두 승인. 귀·꼬리·발 전체와 러그 여백, 자연스럽게 입은 디자인과 네 자세의 손 위치/고개 변화 유지 확인. 수정 담당과 다른 검토자의 승인 후 기존 pet.png를 pet-original.png로 보존하고, 승인된 pet-v2.png를 pet.png에 복사하여 카탈로그4키 등록. 새 시트의 얇은 중앙 경계에 sourceInset2px 적용.
