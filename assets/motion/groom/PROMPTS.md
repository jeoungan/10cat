# Self-grooming motion cutscene sheets

Generated with the built-in `image_gen` tool on 2026-09-08, one call per cat. All source references were visually inspected before generation. Original generated files were preserved; project files are byte-for-byte copies. No image postprocessing or synthetic poses.

Each sheet is a 2 × 2 grid in TL → TR → BL → BR order: raised paw, visible tongue licking same paw, face wash with same paw, lowered paw/relaxed gaze. Runtime should crop equal cells. Tiny separator lines on some grids can be excluded with a 2-pixel inset inside each cell.

Requested size: 2048 × 2048 or higher. Actual built-in output: 1254 × 1254 for every sheet, with 627 × 627 cells. Keep this distinction when reporting resolution.

Reference 1: `assets/cats/<id>.png`, character identity only. Reference 2: `assets/backgrounds/living-room.png`, environment/style.

## Visual QA

All 10 outputs were inspected immediately after generation. All contain four distinguishable drawn action poses, a visible pink tongue in the second frame, paw-to-face washing in the third frame, matching character coat and eye colors, an anatomically plausible grounded cat, and a consistent warm living room. No humans, text, UI or unwanted transparency. Perspective and body positioning are stable enough for illustrated cutscene playback; minor background and fur detail variations remain between generated panels, so these are held animation drawings rather than optical-flow video. Hodu's large tail approaches/crops the lower-right framing edge consistently; this does not obscure the grooming motion. Some final frames relax with open or half-open eyes instead of the requested blink.
