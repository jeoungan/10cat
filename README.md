# 나른한 오후

열 마리의 고양이와 함께 사는 2D 일러스트 돌봄 게임입니다. 햇살 거실, 포근한 침실, 보호망으로 둘러싸인 초록빛 테라스를 오가며 고양이들의 몸 상태와 기분을 살피고, 친밀도를 쌓아 선택지가 있는 짧은 이야기를 만납니다.

## 바로 실행하기

휴대폰에서는 [나른한 오후 온라인 게임](https://jeoungan.github.io/10cat/)을 Safari나 Chrome으로 열어 플레이할 수 있습니다. 로그인이나 앱 설치가 필요하지 않으며, PC가 켜져 있거나 같은 Wi-Fi에 연결되어 있을 필요도 없습니다. 진행 상황은 기기와 브라우저마다 따로 저장됩니다.

Windows에서 이 폴더의 **Play.cmd를 두 번 클릭**하세요. 실행기가 설치된 Node.js를 찾고, 없으면 현재 사용자 계정의 Codex 번들 런타임을 확인합니다. 게임 서버를 숨겨진 창으로 시작한 뒤 기본 브라우저에서 [나른한 오후](http://127.0.0.1:4173/)를 엽니다. 이미 같은 게임이 실행 중이면 해당 서버를 재사용합니다.

터미널에서 실행하려면 이 폴더로 이동한 뒤 다음 명령을 사용하세요. 서버가 시작되면 위 링크를 열면 됩니다. 게임 실행에는 별도의 npm 패키지 설치가 필요하지 않습니다.

```powershell
npm start
```

`npm start`로 시작한 서버는 해당 터미널에서 `Ctrl+C`로 종료할 수 있습니다. Play.cmd로 시작한 서버는 브라우저 창을 닫아도 실행 중이며, 다음 실행 때 재사용합니다. 재부팅하면 서버도 종료됩니다. 다른 프로그램이 포트 4173을 사용하는 경우 실행기는 오류를 표시하고 멈춥니다. 다른 프로그램을 자동으로 종료하지 않습니다. 시작 로그와 오류 기록은 `output` 폴더에 저장됩니다.

## 돌봄과 이야기

- 고양이 카드를 누르면 함께할 친구를 선택합니다. 방 안의 고양이 또는 오른쪽 초상화를 누르면 큰 일러스트가 열립니다. 확대 화면의 고양이를 눌러 쓰다듬을 수도 있습니다.
- 포만감, 수분, 에너지, 행복, 청결, 건강을 살펴 밥 주기, 물 갈아주기, 함께 놀기, 쓰다듬기, 빗질, 화장실 청소, 재우기, 간식 주기를 선택하세요. 사료와 간식은 재고를 사용합니다.
- 함께 놀기에서는 움직이는 깃털을 세 번 잡습니다. 졸린 고양이는 쉬게 해 주고, 싫다는 반응을 보이면 잠시 기다려 주세요. 돌봄 행동은 고양이의 상태에 따라 다른 결과를 냅니다.
- ‘천천히 눈인사’, ‘이름 불러주기’, ‘함께 기지개’로 더 가까워질 수 있습니다. 눈인사와 부르기는 짧은 교감 장면으로, 기지개는 움직이는 일러스트로 이어집니다. 고양이마다 행동 후 기다리는 시간이 따로 있어 반복 클릭으로 친밀도를 얻을 수 없습니다.
- 친밀도 24를 채우면 해당 고양이의 이야기가 열립니다. 대화와 선택지를 끝까지 진행하면 추억 앨범에 기록됩니다. 모은 이야기는 다시 감상할 수 있습니다.
- 열 마리의 두 선택지마다 다른 반응 대사가 이어집니다. 이야기를 읽다가 새로고침해도 고른 선택과 페이지가 유지되며, 재감상에서 다른 선택을 골라도 첫 완주 보상이 중복 지급되지 않습니다.
- 보리·모찌·루나의 이야기 마지막에는 전용 추억 일러스트가 등장합니다. 모찌의 ‘구름 한 조각의 무게’는 무릎에 턱을 기댄 모습, 루나의 ‘달빛 아래의 인사’는 밤 독서 중 맞은편 의자에서 눈을 감고 앞발을 접은 모습을 담았습니다. 처음 이야기를 마치면 앨범 카드도 해당 그림으로 바뀌며, 이전에 완주한 저장에도 바로 반영됩니다.
- 오늘의 작은 약속과 일일 선물로 코인을 얻고, 작은 상점에서 사료·간식·장난감을 구입합니다. 함께한 행동은 돌봄 일기에 남습니다.
- 환경 설정에서 돌봄 효과음과 움직임 줄이기를 조절할 수 있습니다.

## 움직이는 돌봄 컷신

고양이마다 **머리 쓰다듬기, 빗질 받기, 앞발을 핥고 얼굴을 닦는 그루밍, 먹기, 물 마시기, 기지개**를 별도로 그린 연속 일러스트가 있습니다. 한 동작에 네 가지 실제 자세를 사용하며, 짧은 전환과 반복 재생으로 동작을 이어 줍니다.

- 쓰다듬기·빗질·식사·간식·물·기지개 돌봄에 성공하면 해당 고양이의 동작 컷신이 자동으로 열립니다. 잠에서 깨워 준 뒤에는 기지개를 켭니다. 잠든 동안 물을 갈아줄 때는 잠을 유지하며, 피곤하거나 자극이 많아 거절한 경우에는 거절 안내를 유지합니다.
- 우리 집 돌봄 버튼 아래의 **‘그루밍 보기’ 또는 ‘쓰다듬기 보기’**, 확대 일러스트의 **‘움직이는 작은 순간들’**로 감상 화면을 열 수 있습니다. 지금 입고 있는 옷으로 준비된 동작을 먼저 보여 줍니다.
- 컷신은 별도의 재생 조작 없이 자동으로 이어집니다. 다른 동작 버튼에는 현재 고양이와 의상으로 실제 제작된 시퀀스만 표시합니다.
- 그림 아래의 짧은 문구는 동작이 반복되는 동안 고정되어 편안하게 읽을 수 있습니다.
- `Escape`는 장면을 닫습니다. 일시정지·다시 보기·자세 선택 버튼은 사용자의 요청에 따라 제거했습니다.
- 장면 감상은 친밀도나 자원을 반복 지급하지 않습니다. 움직임 줄이기가 켜져 있으면 정적인 일러스트로 감상합니다.
- 선택한 장면의 이미지 한 장만 불러오며, 화면을 닫거나 다른 장면으로 바꾸면 이전 재생을 정리합니다.

원본 시퀀스는 `assets/motion/{pet,brush,groom,feed,drink,stretch}/`에 있습니다. 내장 `image_gen`으로 생성한 2×2 연속 그림의 각 칸을 브라우저에서 직접 표시하며, 기존 이미지를 흔드는 효과와 달리 눈·머리·손·앞발 자세 자체가 바뀝니다. 프롬프트 전문과 제작 검토 기록은 각 동작 폴더의 `PROMPTS*.md`에 있습니다.

전체 동작 검증: `node tests/motion-browser.mjs`. 자동 재생·원래 화면 복귀, 10마리의 60개 시퀀스, 모바일, 저장 수치 중복 변경 방지, 로딩 실패 후 다시 시도를 검사합니다. 실제 재생 캡처는 `output/motion-qa/groom-preview.webm`입니다.

## 작은 옷장

메뉴의 ‘작은 옷장’, 우리 집의 고양이 옷장 버튼, 확대 일러스트의 ‘꾸며주기’로 들어갑니다. 고양이와 옷을 선택하면 미리 입은 모습을 볼 수 있습니다. 미리보기는 실제 착용 상태나 코인을 바꾸지 않습니다.

| 옷 | 게임 내 코인 | 소재와 분위기 |
|---|---:|---|
| 장밋빛 리본 목걸이 | 처음부터 보유 | 작은 분홍 리본 목걸이 |
| 세이지 스카프 | 35 | 차분한 초록빛 면 스카프 |
| 라일락 니트 베스트 | 65 | 앞발을 가리지 않는 포근한 니트 |
| 크림 세일러 칼라 | 80 | 가는 남색 테두리의 작은 크림색 옷깃 |

한 번 구입한 옷은 열 마리 모두에게 입힐 수 있습니다. 구입 뒤 ‘입혀주기’로 적용하며, 고양이별 착용 상태가 저장됩니다. ‘원래 모습도 좋아요’를 고르고 장신구를 벗길 수 있습니다. 쉬고 있거나 접촉에 피로한 고양이에게는 나중에 입혀 줍니다. 착용과 구매로 친밀도 보상은 생기지 않습니다.

열 마리의 네 가지 착장, 총 **40종을 자연스럽고 포근한 화풍으로 다시 그렸습니다.** 리본과 스카프는 작고 가벼운 면 소재로, 베스트는 몸의 곡선에 맞는 얇은 니트로, 세일러는 작은 칼라로 표현했습니다. 털이 옷깃 위로 포개지고 접촉 그림자가 생기도록 고양이와 옷을 한 장면으로 함께 그렸습니다. 실제 투명 PNG 원본은 `assets/wardrobe-v2/`, 정확한 생성·수정 프롬프트는 같은 폴더의 `PROMPTS*.md`에 있습니다. 기존 의상 소유와 고양이별 착용 저장은 이어집니다.

꾸민 모습은 우리 집·확대 일러스트·일반 이야기·교감·돌봄 컷신에 이어집니다. **모든 고양이의 네 착장으로 쓰다듬기 40개**, **보리·모찌·루나·나비의 네 착장으로 그루밍 16개**, 총 **56개 착용 동작 시퀀스와 224개 자세**를 별도로 그렸습니다. 손길에 머리를 기울이거나 눈을 감고, 앞발을 핥고 얼굴을 닦는 자세가 실제로 바뀝니다. 옷장에서 ‘입혀주기’를 누른 뒤 우리 집에서 쓰다듬어 보세요. 보리·모찌·루나·나비는 ‘그루밍 보기’로 감상하거나 컷신의 동작 버튼으로 쓰다듬기와 그루밍을 오갈 수도 있습니다.

아직 착용 시퀀스가 없는 동작은 선택한 옷을 유지하는 정적인 일러스트로 감상합니다. 해당 돌봄의 수치·재고 변화는 정상 적용되며, 옷을 벗은 동작이나 다른 행동의 그림으로 바꾸지 않습니다. 나머지 착용 동작은 향후 추가 제작할 수 있습니다. 전용 추억 CG는 기존 이야기의 고정 그림이며, 현재 착장에 따라 바뀌지 않습니다.

착용 시퀀스는 `assets/motion/wearing/{cat}/{outfit}/{action}.png`에 있습니다. 검수된 조합만 `wearing-motion.js`에 등록하며, 원본 치수·SHA256·용량·자세 수는 `assets/motion/wearing/manifest.json`, 의상 원본과 자르기 좌표는 `assets/wardrobe/manifest.json`에 기록합니다. 선택한 동작 시트 한 장을 필요할 때 불러옵니다.

검증: `node tests/expansion-browser.mjs`. 새 상호작용과 컷신, 미리보기·구매·착용·해제·저장복원, 40개 의상 모습, 모바일을 검사합니다. 결과와 스크린샷은 `output/expansion-qa/`에 저장합니다.

새 옷장 40종의 실제 투명도·프레임·데스크톱·모바일 화면은 `node tests/wardrobe-v2-browser.mjs`, 착용한 상태의 돌봄·실제 자세 변화·의상 저장·보상 중복 방지·로딩 재시도·모바일·착용 해제는 `node tests/wearing-browser.mjs`로 검사합니다. 근거는 각각 `output/wardrobe-v2-review/`와 `output/wearing-qa/`에 저장합니다.

착용 그루밍을 추가할 때는 `node tests/wearing-groom-browser.mjs --cat=nabi --output=output/review-1538`처럼 해당 고양이와 새 증거 폴더를 지정해 검사합니다. 네 착장의 실제4자세, 홈/확대 감상 진입, 쓰다듬기와의 왕복, 저장 복원, 감상 무보상과 움직임 줄이기를 확인합니다. 모찌·루나·나비 원본과 정확한 생성·동작 교정 기록은 각각 `assets/motion/wearing/{cat}/PROMPTS-groom.md`에 있습니다.

마우스 클릭과 터치로 조작합니다. 키보드는 `Tab`과 `Shift+Tab`으로 버튼 사이를 이동하고 `Enter` 또는 `Space`로 선택합니다. 확대 일러스트, 이야기, 설정 등의 창은 `Escape`로 닫습니다. 대화는 ‘다음’ 버튼과 화면의 선택지로 진행합니다.

## 저장과 시간

진행 상황은 **현재 브라우저의 로컬 저장소에 자동 저장**됩니다. 같은 브라우저에서 같은 주소 `http://127.0.0.1:4173/`로 다시 열면 이어서 플레이합니다. 브라우저나 프로필이 다르면 기록이 별도이며, 시크릿 창이나 사이트 데이터 삭제는 저장에 영향을 줄 수 있습니다. 환경 설정의 ‘지금 저장하기’로 수동 저장도 가능합니다. 저장 공간을 사용할 수 없는 경우 게임 안에서 안내합니다.

게임 화면이 보이는 동안 시간이 흐릅니다. 설정·이야기·컷신 등의 대화창을 열거나 탭을 숨겨 둔 동안에는 실시간 갱신이 잠시 멈추며, 재접속 시에는 게임의 복귀 계산에 따라 상태가 반영됩니다. 실제 반려묘 생활을 바탕으로 한 게임용 시뮬레이션입니다.

## 일러스트와 프로젝트 파일

고양이 열 마리는 내장 이미지 생성 도구로 **각각 독립된 PNG 일러스트**로 제작했습니다. `assets/cats`의 투명 배경 고양이 이미지와 `assets/backgrounds`의 공간 일러스트를 합성해 보여 줍니다. 프롬프트와 제작 기록은 각 폴더의 `PROMPTS*.md`에 있습니다.

주요 파일은 `index.html`(화면 진입점), `app.js`(화면·상호작용), `game.js`(돌봄·저장·이야기 로직), `style.css`와 `polish.css`(화면 디자인), `server.mjs`(로컬 서버)입니다.

현재 온라인 게임은 **GitHub Pages**에서 `main` 브랜치의 루트를 정적으로 제공합니다. `.nojekyll`은 별도의 문서 변환 없이 게임 파일을 그대로 제공하도록 지정합니다. `main`에 푸시하면 온라인 게임도 갱신됩니다.

다른 정적 호스팅에 사용할 실행 파일은 `npm run build` 또는 `npm run build:site`로 `dist/`에 준비할 수 있습니다. 이 폴더에는 게임 실행 파일과 일러스트만 복사하며, 생성된 `dist/`는 Git에서 제외합니다. `.openai/hosting.json`은 이전 Sites 배포 시도의 식별자를 보존한 설정입니다. 해당 배포는 256 MiB 제한으로 실패했으며 현재 서비스는 GitHub Pages를 사용합니다.

## 검증 명령

돌봄 수치, 이야기, 보상, 구매와 저장 관련 로직은 Node.js의 내장 `node:test`로 검증합니다.

```powershell
npm test
```

브라우저 검증은 서버를 먼저 실행한 상태에서 아래 명령을 사용합니다. Playwright와 Chrome이 필요하며, 이 작업 환경에서는 Codex의 번들 Playwright 경로도 확인합니다. 자동 검증은 별도의 브라우저 컨텍스트를 사용합니다. 스크린샷과 결과는 `output/qa`에 저장합니다.

```powershell
node tests/browser-check.mjs
```

선택지의 실제 후속 대사·새로고침·재감상 보상·모바일 대화창은 `node tests/story-branches-browser.mjs`로 검증합니다. 해당 화면과 결과는 `output/story-qa/`에 저장됩니다.

모찌 전용 CG와 수집 후 앨범 표시, 착용 의상 복귀, 저장된 마지막 장면과 기존 보리/다른 고양이 화면은 `node tests/memory-cg-browser.mjs`로 확인합니다. 근거는 `output/review-1143/`, 새 그림 원본과 정확한 제작 프롬프트는 `assets/backgrounds/mochi-memory.png` 및 `assets/backgrounds/PROMPTS-mochi-memory.md`에 있습니다.

루나 CG의 1440/390/320px 구도·대화·키보드·앨범과 고양이 전환 후 저장 복원은 개발 중 로컬 검증을 마쳤습니다. 당시 일회성 검사 스크립트는 `output/ui-review-1211/check-luna.mjs`와 `output/review-1211/game-cross-cat-review.mjs`에 있습니다. 원본과 제작·검토 기록은 `assets/backgrounds/luna-memory.png`와 `assets/backgrounds/PROMPTS-luna-memory.md`입니다.

`output/`은 로컬에서 생성되는 실행 로그·검수 캡처·일회성 검사 결과 폴더로, Git 저장소에는 포함하지 않습니다. 문서의 과거 `output/` 경로는 개발 당시의 로컬 검증 기록을 가리킵니다. 게임 실행에 필요한 일러스트 원본과 정식 검사는 각각 `assets/`와 `tests/`에 포함되어 있습니다.
